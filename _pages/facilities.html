Group workstations

Four Dell Precision 7920 tower workstations, each with dual Intel Xeon Gold 6230 processors and dual NVIDIA Quadro RTX 5000 GPUs, for code development, pre- and post-processing, visualization and mid-size production runs.

On campus

CSULB Central HPC Cluster 2 (HPC2)

The Central HPC environment of the Division of Information Technology (DoIT) gives the group access to shared high-performance hardware and software with professional system administration. The cluster is housed in the University Tier 3 Data Center. The MCF2 Lab is an HPC condo owner under the campus Institution/Condo Model.

1,664CPU cores on 36 nodes
140,800CUDA cores
20GPUs on 5 GPU nodes
19 TBTotal memory
InfiniBandInternal network
1 TBSSD scratch per node

HPC2 configuration as published by CSULB DoIT; operating system Red Hat Enterprise Linux 8.
