Research themes

Our projects use a common set of methods. Population balance equations describe the size of particles, droplets and bubbles, and transported probability density functions describe turbulent mixing. We solve both with quadrature-based moment methods in OpenFOAM, check the solvers against analytical solutions and compare the results with experimental data.

Open-source software

Software developed in the lab and by its members, released under open-source licenses.

{% include icon.html name="droplet" size=24 %}

Mirab

A free, cross-platform desktop application for modeling water distribution and stormwater systems. Mirab puts EPA EPANET 2.2, OWA EPANET 2.3, EPANET-MSX, EPA SWMM 5.2 and the SWMM5+ finite-volume solver behind one interface, with live results, calibration, scenarios, GIS exchange, a command-line interface and a Python package.

GitHub {% include icon.html name="external" size=14 %} · Documentation {% include icon.html name="external" size=14 %} · Zenodo {% include icon.html name="external" size=14 %}

{% include icon.html name="flame" size=24 %}

ceaToFoam

Turns NASA CEA chamber thermochemistry into ready-to-run OpenFOAM cases for liquid-rocket thrust chambers and nozzles: a consistent frozen-flow thermophysical model, the nozzle contour and the mesh, for repeatable studies across propellants and operating points. Developed with Luke Cerda.

GitHub {% include icon.html name="external" size=14 %} · Zenodo {% include icon.html name="external" size=14 %}

SWMM5+ engine

A conservative finite-volume engine for EPA's Storm Water Management Model, written for parallel and high-performance computing during a postdoc at UT Austin.
